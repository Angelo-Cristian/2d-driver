# 🎮 2D Driver
Get the packages and deliver them to the customers in this 2D driver game made with Unity.

---

## 🛠️ Technical details
* **Driving system** -> It was made with Unity's Input System (WASD / Arrow Keys).
* **Speed boost** -> If the car collides with an object that has the "SpeedBoost" tag, it gets a speed boost until it collides with an obstacle.
* **Delivery system** -> If you collide with a package (square), you collect it, and when you collide with a customer (circle), you deliver the package (the color change of the car indicates whether you have a package or not).
* **Collision system** -> If you collide with an obstacle, the car's speed is reduced. You can also interact via collision with packages and customers (see Delivery system).
