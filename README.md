# 🎮 2D Driver
Get the packages and deliver them to the customers in this 2D driver game made with Unity.
<img width="938" height="452" alt="2D driver" src="https://github.com/user-attachments/assets/a455312c-122d-4cff-b4c2-01514bd57f57" />

## 🛠️ Technical details
* **Driving system** -> it was made with the Unity's input system (WASD/(UP, LEFT, DOWN, RIGHT))
* **Speed boost** -> if the car collides with an object that has the "SpeedBoost" tag, it gets a speed boost until it collides with an obstacle
* **Delivery system** -> if you collide with a package(square), you'll collect it, and when you'll collide with a customer(circle), you'll send the package (the color change of the car indicates if you have a package or not)
* **Collision system** -> if you collide with an obstacle, you'll have the car's speed reduced and you can also collide with the packages and the customers (see Delivery system)
